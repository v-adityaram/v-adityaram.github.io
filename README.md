
## Pages

- `index.html` - Homepage with hero, about, skills, featured projects, experience, architecture, certifications, resume, and contact.
- `projects.html` - Detailed project showcase for AutoCat, PAPERBRIEF AI, and SEO using NLP.
- `style.css` - Shared dark enterprise SaaS styling, responsive layouts, glass cards, and visual system.
- `script.js` - Mobile navigation, sticky header state, scroll reveal animation, and project filtering.

## Asset Notes

Place the final resume at:

```text
assets/Resume.pdf
```

Future project screenshots can be added to `assets/` and swapped into the visual panels in `projects.html`.
