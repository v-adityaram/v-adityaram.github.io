Client POC · built at TCS · 2026

Telecom customer assistant — chat and real-time voice

A customer-service assistant for a telecom operator that answers account questions by text or by talking to it. Deterministic-first: an intent router with confidence gating, a clarifying question when it's unsure, and a LangGraph plan→fetch→answer graph only for questions that need several lookups at once. Voice runs on Azure OpenAI's Realtime API over WebRTC and switches language mid-call. Four agent stacks explored along the way; the current build runs on LangGraph, with a self-hosted Microsoft Agent Framework version still in the running.
