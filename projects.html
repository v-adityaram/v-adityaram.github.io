Telecom customer assistant — chat and real-time voice

A customer-service assistant for a telecom operator: plan, device, balance, purchases and offers, asked in plain language by chat or in a live voice call that switches language when the caller does. A confidence-gated router keeps most turns to one model call and a template; a LangGraph plan→fetch→answer graph handles only the questions that need several lookups at once; an allow-listed tool layer is the only way out to the telecom APIs. Four agent stacks — Azure AI Foundry prompt agents, Foundry hosted agents on the Microsoft Agent Framework, MAF self-hosted, LangGraph — were explored; the current build runs on LangGraph, with the self-hosted MAF version still in the running.

Budget — a daily expense tracker with an AI assistant

A monthly spending budget becomes a daily allowance; unspent money rolls to tomorrow or into savings, overspending always carries forward. Tracks income, fixed commitments, bank and cash accounts, cards, loans and locked assets, with optional automatic balance sync and a reality-check reconciler. The assistant takes text or voice and proposes every change for a confirm tap: common shorthand ("200 uber hdfc") is parsed locally with typo-tolerant matching against real accounts and past tags, no model call; anything open-ended goes to Gemini with an automatic Cloudflare Workers AI fallback.

Ask about Aditya — a RAG assistant for this site

Ask it anything about my work and it answers from what is actually on this site and my resume, citing where it looked. A small set of hand-written content chunks is embedded with a Workers AI model and stored in Cloudflare Vectorize; a question is embedded the same way, the corpus is ranked against it, and Gemini writes the answer under a strict rule: only from the context, in the third person, and say "that isn't on the site" rather than guess. Cloudflare Workers AI takes over automatically if Gemini is unavailable.

The corpus is small enough that a top-K cutoff turned out to be a liability — the first version dropped the one chunk a recruiter's question needed. It now gives the model the whole corpus and uses the vector scores to rank citations against the answer that was actually written, which is a more honest source trail than similarity to the question.
